# SharePoint Utils (SharePoint 検索ツール)

SharePoint Utils は、SharePoint のドキュメントライブラリ内のファイルを高速かつ簡単に検索・アクセスするための Google Chrome 拡張機能です。ポップアップ設定ではなく、ブラウザ画面上にモーダルとして表示されるため、作業を中断することなく検索が可能です。

## ✨ 主な機能

- **超高速リアルタイム検索**: ファイル名を3文字以上入力するだけで自動検索を開始します。
- **ファイル & フォルダへのダイレクトアクセス**: 
  - ファイルをクリックすると SharePoint の Web ビューアで直接開きます（ダウンロードされません）。
  - フォルダアイコン（📂）をクリックすると、ファイルが保存されているディレクトリにジャンプします。
- **複数サイト検索**: 複数の SharePoint サイトを登録し、すべての登録サイトを横断して検索できます。
- **サイトごとのサブフォルダ管理**: サイトごとにサブフォルダを追加・編集・削除し、検索結果の絞り込みに利用できます。
- **ローカル設定の保持**: 登録サイトとサイトごとのサブフォルダ設定をブラウザ内に保存し、次回以降もそのまま利用できます。

---

## ⚙️ インストール方法

1. Google Chrome を開き、アドレスバーに `chrome://extensions/` と入力して Enter キーを押します。
2. 画面右上の **「デベロッパー モード (Developer mode)」** のスイッチを **オン** にします。
3. 画面左上の **「パッケージ化されていない拡張機能を読み込む (Load unpacked)」** をクリックします。
4. パソコンに保存されているこの拡張機能のフォルダ (`SharePoint File Search` フォルダ) を選択します。
5. 「SharePoint Utils」がインストールされたことを確認します。ピン留め（📌）しておくと便利です。

## 📖 使い方

本ツールを使用するには、**対象の SharePoint サイトがブラウザのタブで開かれており、ログイン済みであること** が必要です。

拡張機能アイコンをクリックすると、画面中央に検索画面（モーダル）が表示されます。

### タブ 1: 🔍 Search (検索)

- **自動検索**: 検索バーに3文字以上入力すると、登録済みのすべてのサイトの `Shared Documents` を横断検索します。
- **フィルター**: `Site` と `Folder` のドロップダウンを組み合わせて、特定サイト内の特定サブフォルダまで絞り込めます。
- **ファイル閲覧**: ファイルの行をクリックするとファイルを直接開きます。
- **フォルダ移動**: ファイル名の下に表示されるパスはフォルダのパンくずリンクになっており、各階層を直接開けます。

### タブ 2: ⚙️ Settings (設定)

- **Add Site**:
  - SharePoint のサイト名を入力して追加します。(例: `msteams_268a65`)
  - ドキュメントライブラリ URL は `https://dxcportal.sharepoint.com/sites/{site}/Shared Documents` として自動生成されます。
- **Sites**:
  - 登録済みサイトの一覧です。
  - ラジオボタンでデフォルトサイトを選択します。フォルダ追加・編集対象と Search タブの初期 Site フィルターに使われます。
  - 🗑️ 削除: サイトとそのサイト配下のサブフォルダ設定を削除します。
- **Add Subfolder (サブフォルダの追加)**:
  - デフォルトサイトのサブフォルダ (例: `/Reports/2024`) を入力し、`+ Add` ボタンを押します。
  - SharePoint のフォルダ URL をそのまま貼り付けても追加できます。
- **Subfolders (サブフォルダリスト)**:
  - ✏️ 編集: デフォルトサイトに登録したサブフォルダ名を変更します。
  - 🗑️ 削除: デフォルトサイトのサブフォルダを削除します。
