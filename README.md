# SharePoint Utils (SharePoint 検索ツール)

SharePoint Utils は、SharePoint のドキュメントライブラリ内のファイルを高速かつ簡単に検索・アクセスするための Google Chrome 拡張機能です。ポップアップ設定ではなく、ブラウザ画面上にモーダルとして表示されるため、作業を中断することなく検索が可能です。

## ✨ 主な機能

- **超高速リアルタイム検索**: ファイル名を3文字以上入力するだけで自動検索を開始します。
- **ファイル & フォルダへのダイレクトアクセス**: 
  - ファイルをクリックすると SharePoint の Web ビューアで直接開きます（ダウンロードされません）。
  - フォルダアイコン（📂）をクリックすると、ファイルが保存されているディレクトリにジャンプします。
- **サブフォルダ管理**: 検索対象にしたいサブフォルダを自由に追加・編集・削除できます。
- **データキャッシュ化 (ローカルデータ保存)**: 取得したファイル情報をブラウザにローカル保存し、API の制限 (スロットリング) を回避しつつ、いつでも爆速で検索できます。
- **インポート / エクスポート**: 設定とキャッシュされたデータを CSV 形式で出力し、他のブラウザや PC にデータを簡単に引き継げます。

---

## ⚙️ インストール方法

1. Google Chrome を開き、アドレスバーに `chrome://extensions/` と入力して Enter キーを押します。
2. 画面右上の **「デベロッパー モード (Developer mode)」** のスイッチを **オン** にします。
3. 画面左上の **「パッケージ化されていない拡張機能を読み込む (Load unpacked)」** をクリックします。
4. パソコンに保存されているこの拡張機能のフォルダ (`SharePoint File Search` フォルダ) を選択します。
5. 「SharePoint Utils」がインストールされたことを確認します。ピン留め（📌）しておくと便利です。

## 📖 使い方

本ツールを使用するには、**対象の SharePoint サイトがブラウザのタブで開かれており、ログイン済みであること** が必要です。

拡張機能アイコンをクリックすると、画面中央に検索画面（モーダル）が表示されます。

### タブ 1: 🔍 Search (検索)

- **自動検索**: 検索バーに3文字以上入力するだけで、保存されたデータから該当するファイルを瞬時に表示します。
- **フィルター**: 検索バーの横にあるドロップダウンから特定のサブフォルダだけを絞り込んで検索することができます。
- **ファイル閲覧**: ファイルの行をクリックするとファイルを直接開きます。
- **フォルダを開く**: 行の右側にある 📂 ボタンを押すと、ファイルが保存されている SharePoint フォルダに飛びます。

### タブ 2: ⚙️ Settings (設定)

- **Import / Export**:
  - `📤 Export CSV`: ターゲットドキュメントライブラリの URL 設定、現在設定されているサブフォルダ、およびローカル保存されたファイル情報を `sp_search_data.csv` として保存します。
  - `📥 Import CSV`: `.csv` ファイルを読み込んで設定とファイルリストを即座に復元します。
- **Target Document Library URL (対象ドキュメントライブラリ URL)**:
  - 検索対象となる SharePoint ドキュメントライブラリの完全な URL を入力して `Save` を押します。(例: `https://.../sites/msteams/Shared Documents`)
  - ※変更すると、設定されていたサブフォルダと保存データがリセットされます。
- **Add Subfolder (サブフォルダの追加)**:
  - 検索対象に追加したいサブフォルダ (例: `/Reports/2024`) を入力し、`+ Add` ボタンを押します。
- **Subfolders (サブフォルダリスト)**:
  - ☑ チェックボックス: データを更新 (Refresh) するときに、そのフォルダを対象にするかどうか選びます。
  - ✏️ 編集: 登録したサブフォルダ名を変更します。
  - 🗑️ 削除: サブフォルダとその中のキャッシュデータを削除します。
- **🔄 Refresh checked folders**:
  - チェックがついているサブフォルダの最新ファイル一覧を SharePoint サーバーから取得(同期)します。ファイル情報が古い場合に使用してください。
