# SharePoint Utils (SharePoint 検索ツール)

SharePoint Utils は、SharePoint のドキュメントライブラリ内のファイルを高速かつ簡単に検索・アクセスするための Google Chrome 拡張機能です。ポップアップ設定ではなく、ブラウザ画面上にモーダルとして表示されるため、作業を中断することなく検索が可能です。

## ✨ 主な機能

- **高速ファイル検索**: ファイル名を3文字以上入力して Enter を押すと検索を開始します。
- **ファイル & フォルダへのダイレクトアクセス**: 
  - ファイルをクリックすると SharePoint の Web ビューアで直接開きます（ダウンロードされません）。
  - フォルダアイコン（📂）をクリックすると、ファイルが保存されているディレクトリにジャンプします。
- **複数サイト検索**: 複数の SharePoint サイトを登録し、すべての登録サイトを横断して検索できます。
- **大規模ライブラリ対応**: 100件ずつページングし、必要に応じて「Load more results」で追加取得できます。
- **サイト単位の耐障害検索**: サイトごとに検索を実行するため、1サイトのエラーが他サイトの結果を隠しません。
- **検索結果の整理**: ファイル種別、サイト、フォルダ、更新日で絞り込み、名前・日付・サイズで並べ替えできます。
- **お気に入りと履歴**: お気に入り、最近開いたファイル、最近の検索、保存済み検索をローカルに保持します。
- **サイトごとのサブフォルダ管理**: サイトごとにサブフォルダを追加・編集・削除し、検索結果の絞り込みに利用できます。
- **ローカル設定の保持**: 登録サイトとサイトごとのサブフォルダ設定をブラウザ内に保存し、次回以降もそのまま利用できます。

---

## ⚙️ インストール方法

1. Google Chrome を開き、アドレスバーに `chrome://extensions/` と入力して Enter キーを押します。
2. 画面右上の **「デベロッパー モード (Developer mode)」** のスイッチを **オン** にします。
3. 画面左上の **「パッケージ化されていない拡張機能を読み込む (Load unpacked)」** をクリックします。
4. パソコンに保存されているこの拡張機能のフォルダ (`SharePoint File Search` フォルダ) を選択します。
5. 「SharePoint Utils」がインストールされたことを確認します。ピン留め（📌）しておくと便利です。

## 📖 使い方

本ツールを使用するには、**対象の SharePoint サイトがブラウザのタブで開かれており、ログイン済みであること** が必要です。

拡張機能アイコンをクリックすると、画面中央に検索画面（モーダル）が表示されます。

### タブ 1: 🔍 Search (検索)

- **検索**: 検索バーに3文字以上入力して Enter を押すと、登録済みサイトのライブラリを横断検索します。
- **フィルター**: `Site` と `Folder` のドロップダウンを組み合わせて、特定サイト内の特定サブフォルダまで絞り込めます。
- **並べ替えと日付フィルター**: relevance、ファイル名、更新日時、サイズで並べ替え、「Modified after」で更新日を絞り込めます。
- **追加読み込み**: 結果が100件を超える場合は `Load more results` を押して続きの結果を読み込めます。
- **ファイル閲覧**: ファイルの行をクリックするとファイルを直接開きます。
- **フォルダ移動**: ファイル名の下に表示されるパスはフォルダのパンくずリンクになっており、各階層を直接開けます。

### タブ 2: ⚙️ Settings (設定)

- **Add Site**:
  - SharePoint のサイト名、またはドキュメントライブラリの完全な URL を入力して追加します。(例: `msteams_268a65`、`https://tenant.sharepoint.com/teams/project/Documents`)
  - 完全 URL を入力した場合は、テナント、`/sites/` または `/teams/`、ライブラリ名を自動的に保持します。サイト名だけの場合は既定のテナントと `Shared Documents` を使用します。
- **Sites**:
  - 登録済みサイトの一覧です。
  - ラジオボタンでデフォルトサイトを選択します。フォルダ追加・編集対象と Search タブの初期 Site フィルターに使われます。
  - 🗑️ 削除: サイトとそのサイト配下のサブフォルダ設定を削除します。
- **Backup & Sync**:
  - `Export JSON` でサイト、ライブラリ、サブフォルダ、デフォルトサイトをバックアップできます。
  - `Import JSON` でバックアップを復元できます。現在のサイト設定はインポート内容で置き換わります。
  - `Sync sites and folders across Chrome` を有効にすると、Chrome の `storage.sync` を使って同じ Chrome プロフィール間で設定を同期します。既存の同期データがある場合は、Local をアップロードするか Chrome プロフィールの設定をこの端末へ適用するかを選択できます。
  - Sync が有効な間は、変更をまず Local に保存してからプロフィールへ自動コピーします。再度開いたときはプロフィール側の設定が Local に適用されます。Sync を無効にしても、プロフィール側のデータは削除されません。
- **Add Subfolder (サブフォルダの追加)**:
  - デフォルトサイトのサブフォルダ (例: `/Reports/2024`) を入力し、`+ Add` ボタンを押します。
  - SharePoint のフォルダ URL をそのまま貼り付けても追加できます。
- **Subfolders (サブフォルダリスト)**:
  - ✏️ 編集: デフォルトサイトに登録したサブフォルダ名を変更します。
  - 🗑️ 削除: デフォルトサイトのサブフォルダを削除します。

## 開発者向けチェック

依存関係やビルドステップは不要です。変更後は次のコマンドで構文と helper のテストを実行できます。

```text
node --check background.js
node --check content-utils.js
node --check content.js
node --test tests/content-utils.test.mjs
```
